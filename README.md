# 나만쓰는메모

노트, 할 일, 캘린더, 주간업무 자료를 한곳에서 다루는 Windows 데스크톱 메모 앱입니다. 노트는 이 PC에만 저장합니다.

이 저장소에는 설치 파일만 올립니다.

## 설치

1. [Releases](../../releases/latest)에서 `my-memo-<버전>-windows-x64.zip`을 내려받습니다.
2. 압축을 풀고 `install.cmd`를 실행합니다.
3. 바탕 화면이나 시작 메뉴의 **나만쓰는메모** 아이콘으로 엽니다.

64비트 Windows 10 이상에서 쓸 수 있고, 관리자 권한은 필요하지 않습니다.

## 업데이트

앱의 **설정 → 버전 정보**에서 **업데이트 확인**을 누르면 새 버전이 있는지 확인하고, 있으면 내려받아 설치합니다. 노트와 설정은 그대로 남습니다.

버전 0.1.2 이하에는 이 버튼이 없습니다. 위의 설치 순서를 한 번 더 따라 새 버전을 설치해 주세요. 기존 노트는 지워지지 않습니다.

## 제거

압축을 푼 폴더의 `uninstall.cmd`를 실행합니다. 앱만 제거하고 노트는 지우지 않습니다.
